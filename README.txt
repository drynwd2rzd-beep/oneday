OneDay v4.2

本次修改：
- 新增“导入数据”：选择 OneDay 导出的 JSON 备份后可恢复数据，导入前二次确认，避免误覆盖。
- 新增“恢复初始设置”：重置主题、主题色、头像等设置，不删除记录、事项、计划和统计数据。
- 修复旧数据兼容中的 uuid / uid 错误，避免部分旧数据缺少 ID 时加载异常。
- 修复每日循环事项的开始日期逻辑，循环事项不会错误计入创建日前的统计。
- 修复统计页“已完成”筛选：按完成次数识别，循环事项完成后也会出现在已完成中。
- 完成概览精简为“累计完成”和“连续坚持”。
- 连续坚持规则：当天存在事项时，只有当天全部事项完成才算一个坚持日；没有安排事项的日期不计入也不主动打断此前连续记录。
- 已完成 / 未完成柱状图与图例使用明显不同的颜色。
- 优化“我的”页面设置行左右内边距，图标不再贴近边框。
- 重做回顾记录排版：日期层级、记录数量、单条记录卡片与时间信息更清晰。

自检：
- JavaScript 已通过 Node 语法检查。
- 已检查新增导入控件、恢复初始设置、统计指标与对应函数/ID 是否存在。
- 已检查项目中不再存在 uuid() 未定义调用。

使用：解压后直接打开 index.html。
