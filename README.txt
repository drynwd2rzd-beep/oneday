OneDay v4.8.4

个人成长记录应用

当前版本功能

0. 首页模块自定义
- 首页模块支持显示或隐藏
- 支持调整模块顺序
- 当前可自定义：问候与日期、今日事项、值得留下、今日完成情况、我的计划
- 设置保存在设备本地，并包含在数据导入导出与恢复初始状态中

1. 今天
- 查看当天事项
- 直接完成或取消完成事项
- 添加新的事项
- “值得留下”可记录当天的想法
- 首页只保留输入入口，不重复展示已保存的历史记录

2. 事项
- 管理一次性事项和循环事项
- 完成、取消完成、删除事项
- 按日期查看事项
- 查看事项的累计完成天数统计

3. 计划
- 创建长期计划
- 编辑计划
- 暂停、重新进行、完成或归档计划
- 已完成与已归档内容可收起
- 计划不使用百分比进度条

4. 回顾
- 按日期查看过去留下的记录
- 支持查看不同日期
- 以时间线方式浏览成长记录
- 回顾页面不显示完成率或“几/几已完成”之类的任务成绩信息

5. 我的
- 更换头像
- 浅色、深色或跟随系统主题
- 数据导出
- 数据导入
- 恢复初始状态
- 查看版本信息

数据说明
- 数据保存在设备本地
- 导出数据可用于备份
- 导入数据前请确认备份文件来源和内容
- 恢复初始状态会清除当前应用数据，请谨慎操作

当前统计设计
- 统计页面仅保留各事项累计完成过多少天
- 不包含周期趋势图
- 不包含日期轴、方格趋势图或旧统计筛选器

版本
OneDay v4.8.4


v4.8.3 — 回顾重构
- 回顾从单纯文字列表升级为“时间线 + 单日回看”。
- 时间线按月份组织，显示真实记录与完成事项，不新增统计页。
- 点击日期可进入“那一天”，查看当天留下的文字与事项完成状态。
- 回顾日历会标记有真实活动的日期。


v4.8.4 — 回顾双视图
- 回顾首页压缩介绍区域，减少页面顶部冗余。
- 新增“时间线 / 完成概览”双视图。
- 完成概览支持按月份切换查看。
- 月度完成次数基于真实事项完成记录自动计算。
- 按事项展示当月完成次数与相对完成量。
- 增加当月文字记录天数与活跃天数。
