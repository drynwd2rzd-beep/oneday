OneDay · v4 本地开发版

本次修复与优化：
- 首页右上角不再显示设置；设置只在“我的”页面
- “值得留下”支持一天多条记录，并兼容旧数据格式，避免出现 undefined
- 首页事项可直接完成
- 移除自动生成的默认“阅读”事项，避免事项数量无故多一条
- 事项页新增累计完成次数与每个事项的完成次数统计
- 日历保留循环事项与单次事项的独立完成记录
- 计划页不使用进度条
- 计划按“进行中 / 已完成 / 已归档”管理，其中已完成和已归档为可展开收起区域
- 回顾页不再展示完成任务数量或完成率，只展示留下的文字记录
- 回顾日历点击日期后真正切换到该日期的记录
- 整体字体进一步缩小，保持信息层级但减少压迫感
- 全局按钮、卡片、输入区域统一使用圆角视觉
- 本地数据增加结构规范化，降低旧版本数据导致 undefined 的风险
- 已通过 JavaScript 语法检查、DOM ID 引用检查、onclick 函数引用检查

文件：
- index.html：完整应用
- manifest.json：PWA 配置
