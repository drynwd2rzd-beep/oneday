OneDay v4.1

本次修改：
- 修复“值得留下”旧数据兼容，避免 undefined / 英文字段错误。
- 值得留下支持一天多条记录，首页仅预览最近三条，完整记录在回顾。
- 事项改为：今日 / 日历 / 统计三页签；支持完成次数、7 天统计、累计完成、连续天数、完成率。
- 计划页面保留长期方向，不使用进度条；已完成与已归档收纳为可展开区域。
- 回顾不再显示任务完成成绩，只显示真实记录；右上角日期选择有效。
- “我的”页面支持更换头像、浅色 / 深色 / 跟随系统、主题色、数据导出、说明与关于。
- 全站统一圆角、缩小过大的字体与间距。

使用：直接打开 index.html。
