OneDay v4.4

本次修改：
- 统计页取消“累计完成 / 连续坚持”两个总指标。
- 改为按具体事项展示完成天数，例如“读书 7 天”，使用独立方框卡片展示。
- “近 7 天 / 近 30 天”会重新计算每个事项在对应周期内完成过的天数。
- 首页进一步压缩卡片高度、内边距和输入框高度，减少页面中偏大的框和空白。
- “恢复初始设置”改为恢复全部初始数据与设置：头像、主题、事项、计划、回顾记录、完成历史和统计数据都会恢复为首次打开 App 的状态。
- 恢复操作增加两次确认，降低误触清空数据的风险。
- 版本号更新为 OneDay v4.4。

自检：
- 已检查 HTML 结构与关键 ID：habitStats、taskChart、restoreModal。
- 已检查统计周期切换会同时刷新具体事项天数与图表。
- 已检查恢复初始设置后会重置任务、计划、记录、完成历史、头像和主题，并重新渲染各页面。
- 已保留导出 / 导入逻辑。
