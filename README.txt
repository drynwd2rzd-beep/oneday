OneDay v4.9

个人成长记录应用

当前版本功能

0. 首页模块自定义
- 首页模块支持显示或隐藏（入口移动到「我的」）
- 支持调整模块顺序
- 当前可自定义：问候与日期、今日事项、值得留下、今日完成情况、我的计划
- 设置保存在设备本地，并包含在数据导入导出与恢复初始状态中

1. 今天
- 查看当天事项
- 直接完成或取消完成事项
- 添加新的事项
- “值得留下”可记录当天的想法
- 首页只保留输入入口，不重复展示已保存的历史记录

2. 事项
- 管理一次性事项和循环事项
- 完成、取消完成、删除事项
- 按日期查看事项
- 查看事项的累计完成天数统计

3. 计划
- 创建长期计划
- 编辑计划
- 暂停、重新进行、完成或归档计划
- 已完成与已归档内容可收起
- 计划不使用百分比进度条

4. 回顾
- 按日期查看过去留下的记录
- 支持查看不同日期
- 以时间线方式浏览成长记录
- 回顾页面不显示完成率或“几/几已完成”之类的任务成绩信息

5. 我的
- 更换头像
- 默认浅色、深色或跟随系统主题
- 神话特别版：暗色 / 亮色（入口在「主题设置」）
- 首页自定义入口：在「我的」中管理模块显示与排序
- 数据导出
- 数据导入
- 恢复初始状态
- 查看版本信息

数据说明
- 数据保存在设备本地
- 导出数据可用于备份
- 导入数据前请确认备份文件来源和内容
- 恢复初始状态会清除当前应用数据，请谨慎操作

当前统计设计
- 统计页面仅保留各事项累计完成过多少天
- 不包含周期趋势图
- 不包含日期轴、方格趋势图或旧统计筛选器
